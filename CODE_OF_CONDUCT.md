# Community code of conduct

RustyAuth is committed to a respectful, technically rigorous open-source community.

## Expected behavior

- Be respectful, specific and constructive.
- Critique code and ideas, not people.
- Assume good intent while still requiring evidence for security claims.
- Welcome questions and explain project-specific context without gatekeeping.
- Protect private information, credentials and vulnerability details.
- Disclose conflicts of interest that could affect a technical or security decision.

## Unacceptable behavior

- Harassment, threats, discrimination or sustained personal attacks;
- sexualized language or unwelcome attention;
- publishing another person's private information;
- deliberately exposing credentials or vulnerability details;
- impersonation or claims of endorsement by another project; and
- repeated disruption after a maintainer has set a reasonable boundary.

## Enforcement

For ordinary conduct concerns, contact the repository maintainers privately through GitHub. For a
security issue, use the process in [SECURITY.md](SECURITY.md). Maintainers may edit or remove
contributions, lock discussions or temporarily or permanently restrict participation when necessary
to protect the community or project.

Enforcement decisions should be proportionate, documented privately and free from retaliation.
Good-faith disagreement about security, architecture or evidence is not misconduct.

## Scope

This policy applies in project repositories, issue trackers, review discussions, community spaces
and when someone is officially representing RustyAuth.
